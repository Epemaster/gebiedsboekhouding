# Gebiedsboekhouding.nl

Publieke website voor **gebiedsboekhouding.nl**.

Regionale beslis- en waarderingsinfrastructuur die natuur, water, bodem, economie, brede welvaart, risico, investeringen en gebiedsontwikkeling samenbrengt.

## Publicatie
Deze repository publiceert automatisch via GitHub Pages vanaf de `main` branch.

## Ontwerpprincipes
- generieke publieke positionering, voorlopig zonder expliciete concrete gebiedscases;
- geen gefabriceerde gebieds-KPI's;
- meervoudige waarde blijft zichtbaar;
- gebiedsgericht, herleidbaar, dynamisch en besluitgericht;
- responsive en toegankelijk;
- custom domain: `gebiedsboekhouding.nl`.
